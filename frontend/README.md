# Zia Nursery — Frontend

React 18 + Vite frontend for the Zia Nursery e-commerce app.

See the root [README.md](../README.md) for full project documentation, setup instructions, and deployment guide.

## Quick start

```bash
npm install
npm run dev      # dev server at http://localhost:5173
npm run build    # production build → dist/
```

Requires `frontend/.env.local` with `VITE_API_URL=http://localhost:5001` for local development.
